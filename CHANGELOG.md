## [2026.12.0] - 2026-11-28

The first release: a cosy winter Christmas theme for openSUSE Tumbleweed,
with KDE Plasma, GNOME, Xfce and Sway. Every screenshot in the README was
retaken with this release in a test VM on all four desktops.

### Added

- Winter palette (moonlit night blues, cream, gold, ember-red and fir
  green), dusk and night wallpapers with the chameleon in a Santa hat, and
  a hero image, all recorded in `art/prompts/`
- Gold folders with navy emblems, cream file-type pages with gold emblems,
  snow trash, navy devices, and app, settings and one-colour glyph icons
- Plasma style, colour scheme, global theme with a star-lantern splash,
  SDDM login theme, Plymouth boot splash, GTK 3, GNOME Shell, xfwm4 and
  notification themes, Sway/Waybar/swaync styles and a Firefox theme
- Release archives (`make dist`) with SHA256 sums, built from the tag by
  the release workflow with signed build provenance
